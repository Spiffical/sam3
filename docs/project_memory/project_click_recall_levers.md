Findings from stress-testing the production-realistic click engine (text-agent → MLLM finds missed creatures → SAM3 click masks) on the broadened e2e eval set (`scripts/click_engine_probe.py --eval-e2e`, 16-frame manifest: 12 chinacreek + 4 rank03).

**The recall ceiling on hard frames is a STATIC-CAMOUFLAGE detection problem, not a motion problem.** A pixel-level motion-diff probe (`scripts/motion_diff_probe.py`) over the chinacreek clip showed only ~1 creature per scene actually moves (~95-99% diff coverage); the other 4 are sessile (sea stars/snails/anemones) and sit at 0% even at low thresholds, while frame-wide coverage stays <1%. So a motion-difference pre-pass cannot surface the creatures we miss — they don't move. The single mover is already the most obvious animal and gets caught anyway. **Motion-diff abandoned.**

**Tiled high-res sweep is the working recall lever.** `clicker=iterative_tiled` (A/B-toggleable) runs the iterative clicker, then splits the frame into a 2×2 overlapping grid, upscales each tile, and asks the MLLM to find every creature in the high-res crop. Confirmed at repeats=3 vs baseline `iterative` on 6 frames: recall **0.782 → 0.908 (+0.13)**, IoU(all) 0.708 → 0.821 (+0.11), IoU(detected) unchanged (~0.905 — it adds detections, doesn't change mask quality). Gain is uneven: cc_f042 +0.40 and cc_f024 +0.17 carry it; others move only within noise; cc_f045 flat (has creatures neither approach finds even at high res — a true ceiling).

**The tradeoff is precision.** Tiling raised strays/pass ~5× (4.0 → 21.3) even after the content-based verify pass dropped ~49/pass. "Find every camouflaged creature" over-triggers on high-res substrate texture (~12-15 raw candidates for 5 GT). Tuning (strict gate + precision-tightened prompt) cut e2e strays 21.3 → 12.7 while holding recall 0.92.

**Cutting strays further — what actually works (`scripts/tile_stray_bakeoff.py`).** A click-level paired bake-off (no SAM3 — just "does each placed click land on a GT creature?", which lets every strategy run as its own parallel OS process; base click-strays 4.0 exactly matched e2e baseline, validating the proxy) tested a 2×2 of {wide, conservative} tile prompt × {still, temporal} context, repeats=3 on the 6 hard frames. Results (recall / strays-summed-over-6-frames):
- base (no tile): 0.851 / 4.0  •  S0 wide+still (≈ current prod): 0.977 / 14.67
- **S1 conservative+still: 0.920 / 5.0**  •  S2 wide+temporal: 1.0 / 17.33  •  **S3 conservative+temporal: 0.989 / 8.33**

Two findings, both actionable: (1) **A conservative tile prompt is the dominant stray lever** — reframing "find every camouflaged creature, including small ones" → "MOST crops contain NO animal; empty is the expected answer; click only if confident" collapsed raw candidates ~12→~3.7/frame and cut strays 66% (14.67→5.0) for a small recall dip. (2) **Temporal context (same crop region ±~0.5s, added to the proposal + creature-gate stages) is a RECALL lever, not a precision lever** — counter-intuitively it *raises* strays with a wide prompt (seeing persistence makes the model commit more clicks), but it's what cracks the hardest static-camouflage frame (cc_f059 base 0.73 → still-conservative 0.80 → temporal 1.0). **S3 (conservative + temporal) Pareto-dominates current production on both axes** (recall 0.989 vs 0.92; strays 8.33 vs 12.7) at the cost of extra neighbour-crop MLLM calls; **S1 (conservative, still)** is the cheap lean option that matches shipped recall at ~⅓ the strays. Scope caveat: temporal was applied to proposal+gate only; the click-centering refine loop stayed still-frame. Next: confirm winner in full e2e (with SAM3, repeats=3) before shipping into `som_missed_creatures.py`.

**Model choice — Sonnet 4.6 beats Opus 4.7 for this task; don't switch.** Full-engine A/B (`tile_stray_bakeoff.py engine`, repeats=3, 6 frames, no review): Sonnet recall **0.954** vs Opus **0.759**, Sonnet ≥ Opus on every frame (e.g. cc_f018 1.00 vs 0.60). Opus is more conservative/precise (on rank01@5s it returned a cleaner 4 clicks vs Sonnet's 7) but against GT that conservatism MISSES camouflaged creatures. Recall-first task ⇒ keep Sonnet; strays are cheap to filter downstream, misses are unrecoverable.

**A whole-frame "review all clicks" MLLM pass HURTS — rejected.** Tried a final stage showing every placed click on the full frame, asking to remove strays/dupes + nudge to centre of mass. Cost ~**0.13 recall** (Sonnet 0.954→0.828, Opus 0.759→0.632) for ≤2 fewer strays. Two failure modes: at full-frame resolution it removes camouflaged creatures it can't resolve ("substrate"), and its centre-of-mass MOVES land off small-creature bodies (hit→miss). Dedup-only still lost recall (distinct nearby creatures called "duplicates"). Replaced by (i) centre-of-mass instruction in the ZOOMED per-click refine (reliable, no cost — now in `TASK_CORE` + refine prompts) and (ii) deterministic geometric dedup (`_geom_dedup`, merge within ~30px). MLLM review left behind opt-in `--review`, documented as recall-hurting. **Lesson: existence/precision decisions need the ZOOMED view; the downsampled full frame can't resolve small camouflaged creatures.**

**Note on the `engine` harness:** its click-level path omits the per-click zoomed verify gate, so its absolute strays (~16-19/6-frames) run higher than the gated bake-off (~8) and e2e (~12.7); trust recall for cross-config decisions, confirm strays in full e2e.

**Visual diagnosis of the e2e recall losses (`tile_stray_bakeoff.py diag --frame N`, renders clicks/gate/masks vs GT).** Looked at f045 (0.67) and f042 (0.87). The recall drag is NOT the per-click verify gate — on both frames it dropped only strays (0 real creatures). The dominant loss is **SAM3 MASK GENERATION on the smallest/thinnest creatures**: f045 GT1 (pink brittle-star, thin arms) was `refine_mm` verdict **"abandon"** → empty mask → IoU 0; f042 GT2 (smallest, 1094px) got verdict **"good" but the mask localized onto adjacent substrate** → IoU 0. Compact creatures ≥~2000px mask great (IoU 0.87-0.96); failures cluster at ~1000-1150px and thin/radiating bodies. Secondary loss: occasional CLICKING miss on dark low-contrast corner creatures (f045 GT3). Strays are low (~2-7/frame) and originate in the WHOLE-FRAME finder (still uses recall-seeking prompt, not conservative); the gate trims them. **So the next recall lever is mask-gen (stop abandoning correctly-clicked small/thin creatures; fix tiny-creature mislocalization e.g. box-prompt seed), NOT the gate; and strays could drop further with a conservative whole-frame-finder prompt.** Lesson echoes the global-review finding: conservative MLLM JUDGES (global review, refine_mm abandon) tend to kill recall on hard creatures.

**Full e2e+SAM3 confirmation (`tile_stray_bakeoff.py e2e`, repeats=3, 6 frames).** Recommended engine = Sonnet 4.6 + S3 conservative+temporal tile + centre-of-mass prompts + geometric dedup + per-click verify gate → refine_mm → IoU match. Result **recall 0.874 / IoU(all) 0.792 / IoU(det) 0.906 / strays 6.0**, vs previous tuned-tiled **0.92 / 0.835 / 0.908 / 12.7**. So it MORE THAN HALVES strays (12.7→6.0) for −0.046 recall, −0.043 IoU(all), mask quality unchanged. Full progression: no-tile 0.782/4.0 → untuned tiled 0.908/21.3 → tuned tiled 0.92/12.7 → **new 0.874/6.0**. It's a genuine precision/recall TRADE (the click-level Pareto win shrinks under the IoU≥0.5 threshold + verify gate), not a strict win — pick by stray-tolerance. Temporal tile cracked the hardest frame (cc_f059 0.73→0.93); recall drag is cc_f045 (0.67) where the per-click verify gate over-drops ~3/pass incl. some real creatures. **Next recall lever: soften / make-temporal the per-click verify gate on low-prior frames.**

**Mask-gen is NOT a recall lever — the recall ceiling is the CLICKING stage.** Built `refine_group_mm_zoom` (segment on a zoomed crop around the verified click, never abandon) and `refine_group_mm_hybrid` (full-frame default, zoom fallback only on abandon/empty mask) in click_engine_probe.py, A/B'd at full e2e repeats=3 via `tile_stray_bakeoff.py e2e --maskgen {mm,mmzoom,hybrid}`. Results: mm 0.874/IoU(det)0.906/stray6.0; mmzoom recovers thin/tiny creatures in single-frame diag (brittle-star 0→0.80) but drops IoU(det) ~0.07 with no aggregate recall gain; **hybrid keeps IoU(det) 0.902 but recall 0.839 ≈ mm 0.874 (within repeats=3 noise)** — abandon-recoveries fire too rarely to move the aggregate. Keep hybrid (harmless net: only turns empty masks into real ones) but don't expect recall from it. **Future recall work belongs in CLICKING (finder/tile missing dark/low-contrast camouflaged creatures), not masking** — e.g. finer 3×3 tiling on dark regions, temporal on the whole-frame finder. (`cmd_e2e` is now crash-resumable via per-frame frames_cache.json — needed because laptop-sleep hangs the run on a dead socket; the API client has no timeout.)

**BIGGEST lever found: the vision model. Claude Fable 5 (`claude-fable-5`) crushes Sonnet 4.6 at the clicking stage.** Click-level `engine` A/B (no SAM3, repeats=3, 6 frames, identical S3+COM+dedup pipeline, just swap P.MODEL): **Fable recall 1.00 on EVERY frame (incl. the f059 ceiling that was 0.73 at baseline), strays/pass 10.33** vs Sonnet ~0.93-0.95 recall / ~16-18 strays. Fable strictly dominates — perfect clicking recall AND ~40% fewer substrate strays. Since the recall ceiling was the clicking stage, this is the lever. **Full e2e+SAM3 with Fable (hybrid masks, repeats=3) confirmed it: recall 0.977 / IoU(all) 0.862 / IoU(det) 0.883 / strays 5.0** — vs Sonnet S3 0.874/0.792/0.906/6.0 and old tuned-tiled prod 0.920/.../12.7. Fable wins on recall (+0.10, near-perfect), IoU(all), AND strays (lowest); the only dip is IoU(det) 0.883 vs 0.906, expected because Fable detects MORE hard camouflaged creatures and those marginal ones mask a bit looser. **Switching the vision model to Fable is the single biggest win of the whole effort — bigger than every prompt/tiling/mask-gen lever combined.** Model IDs available via `anthropic.Anthropic().models.list()`: claude-fable-5, claude-opus-4-8/4-7/4-6, claude-sonnet-4-6, etc. Swap model with `tile_stray_bakeoff.py engine/e2e --model claude-fable-5` (sets P.MODEL, routing ALL vision calls — finder, tile, gate, refine, mask-judge — through it).

**The "strays" were mostly REAL creatures the GT missed, not false positives.** Visual inspection of Fable's unmatched masks (`tile_stray_bakeoff.py diag` dumps stray crops to `<frame>/strays/`): visible legs (f059), the same reddish squat-lobster recurring across adjacent frames (f054≈f059), pale crabs with limbs — NONE clearly bare substrate. So strays/pass 5.0 overstated FPs. Added a CONSERVATIVE Fable post-mask verify (`verify_masks` in click_engine_probe, `e2e --verify-masks`): shows Fable each produced mask, drops ONLY confident substrate, keeps anything plausibly animal; unmatched-but-kept masks become CAND_NEW (candidate new labels, saved to `<sroot>/candidates/`). Result (Fable, hybrid, repeats=3): recall 0.977 / IoU(det) 0.883, and the 5.33 strays decompose into **cand_new/pass 4.0 (kept, GT-missed real creatures) + FP/pass 1.33 (dropped substrate)**. So true FP rate ≈0.22/frame, not 5.0; ~¾ of "strays" are net-new real finds. Recall unchanged (verify never touches matched masks). Lesson: with incomplete GT, don't chase the stray count — decompose it; Fable's conservative judgment cleanly separates real-vs-FP (unlike the Sonnet global-review that over-removed). A human spot-check of `candidates/` is the gold standard.

**16-frame validation (Fable, hybrid, verify-masks, repeats=3, `e2e --manifest`):** generalizes decisively. OVERALL **recall 0.977** (identical to the 6-hard-frame result), IoU(det) 0.889, true **FP/pass 2.67 (~0.18/frame)**, cand_new/pass 12.67. New chinacreek frames 0.92-1.00 recall; **rank03 cross-clip frames all recall 1.00 / IoU(det) 0.96-0.97 / FP 0.00** — Fable transfers to a different video cleanly. (`cmd_e2e` now multi-source manifest-aware: per-source SRC + neighbour offsets [1,2,3] frames_dir vs [15,30,45] video; reuses cc_fNNN cache across runs.)

**Production wiring:** `scripts/run_som_missed_creatures.py` already routed all SoM MLLM calls through one `--claude-model` (partial-bound); changed its DEFAULT to `claude-fable-5` (overridable via --claude-model / ANTHROPIC_MODEL). The experimental pipeline extras (S3 tile / COM / dedup / hybrid masks) are NOT ported into production's separate click-discovery path — they were marginal vs the model swap; port deliberately only if needed.

**Full-pipeline orchestrator (`scripts/full_pipeline_run.py`, report `docs/full_pipeline_report.md`).** Production-style run per 10s clip: 3 frames evenly through the clip (near begin/mid/end, ~2s context each) -> Sonnet frame-quality screen -> reuse SAM3+Sonnet first-pass masks as baseline -> Fable engine (B=whole-frame / T=tile) -> hybrid masks -> Fable verify -> match vs first-pass (re-found / cand_new=missed / FP) -> Fable keep-decision -> composite renders. Validated on rank03 (frames 3/7/11): f11 first-pass found 0, Fable recovered a clear fish + small creature (headline value); f7 clean re-find (IoU 0.96); f3 the central fish was double-clicked (B re-found + T 31px away mislabeled cand_new) -> the recurring ~30px B/T near-duplicate inflates cand_new. FP=0 all frames. Findings: whole-frame finder (B) does the work on clean clips; tile (T) only risks duplicates there (its value is hard/camouflaged frames); keep-decision sensibly dropped redundant f3.
