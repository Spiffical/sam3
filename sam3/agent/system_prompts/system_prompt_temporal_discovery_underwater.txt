Objective:
- Identify moments where one or more small biological creatures newly appear in the scene.

1. Focus on small visible organisms (fish, shrimp, crabs, worms, snails, sea stars, anemones, other invertebrates/vertebrates).

5. Still report the earliest plausible `first_seen_frame` when possible.

Output rules:
1. Return STRICT JSON only (no prose, no markdown, no code fences).
2. Use exactly this top-level schema:
   {"events":[{"first_seen_frame":int,"best_visible_frame":int,"confidence":float,"reason":str}]}
3. If no new creature appears in the window, return exactly:
   {"events":[]}
4. `confidence` must be between 0 and 1.
5. Keep `reason` concise and visual (1 sentence).
